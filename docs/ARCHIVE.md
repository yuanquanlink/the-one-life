## 能力边界

- 总结建议与成长画像由本地规则生成，目前没有大模型服务调用。
- AI 新闻通过公开新闻接口获取；网络不可用时显示备用说明。
- 当前没有账号、多设备自动同步、云端个人数据备份或原生 HarmonyOS HAP。
- PWA 安装、离线行为和语音能力受浏览器影响；本次桌面检查不能代替手机真机测试。
- 恢复源码不会恢复部署账号、云端资源或浏览器个人数据。

## 恢复开发入口

1. 按 README 安装锁定依赖并运行静态构建。
2. 打开应用并检查新增记录、刷新保存、导出/导入。
3. 阅读 `docs/VERIFICATION.md` 的已验证范围和已知限制。
4. 页面功能在 `app/page.tsx`，样式在 `app/globals.css`；静态入口在 `static/main.tsx`。
5. 接续修改时保留 `the-one-life:v1` 存储键，兼容已有数据结构和 `normalizeState`。
6. 再决定是否拆分大型页面组件、加入真正的模型调用或账号同步；这些属于后续开发，本次不实施。
